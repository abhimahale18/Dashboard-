# 📊 Online Store Sales Analysis Dashboard (Microsoft Excel)

## 📌 Overview
This project showcases an interactive **Online Store Sales Dashboard** developed in **Microsoft Excel** to analyze over **31,000+ online sales records**. The dashboard provides valuable business insights by visualizing sales performance, customer demographics, order status, sales channels, and top-performing states using Pivot Tables, Pivot Charts, and Slicers.

---

## 🎯 Objectives
- Analyze online store sales performance.
- Track customer purchasing behavior.
- Compare sales across channels and states.
- Monitor order status and delivery performance.
- Build an interactive dashboard for business insights.

---

## 📂 Dataset
- **Dataset:** Online Store Sales Data (2022)
- **Total Records:** 31,000+
- **Columns Include:**
  - Order ID
  - Customer ID
  - Gender
  - Age & Age Group
  - Date & Month
  - Order Status
  - Sales Channel
  - Category
  - Quantity
  - Sales Amount

---

## 📊 Dashboard Features
- 📅 Monthly Sales Analysis
- 📈 Orders vs Sales Comparison
- 👩‍🦰 Sales by Gender
- 👥 Orders by Gender & Age Group
- 🚚 Order Status Distribution
- 🛍️ Sales by Channel
- 🗺️ Top 5 States by Sales
- 🎛️ Interactive Slicers (Month, Channel, Category)

---

## 🔍 Key Insights
- Women contributed the highest share of total sales.
- Amazon generated the highest sales among all sales channels.
- Most orders were successfully delivered.
- Adult customers placed the highest number of orders.
- Sales performance varied significantly across different state
